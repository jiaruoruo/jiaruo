## 一、选型背景与约束

### 1.1 核心约束（来自需求规格）

| 约束项 | 指标 | 来源 |
|--------|------|------|
| 闭环控制周期 | < 2 ms | MC-14 |
| 操控频率 | > 1 kHz | MC-09 |
| 传感器采样 | ≥ 1 kHz | MC-11 |
| 指令延迟 | < 5 ms | MC-12 |
| 感知反馈延迟 | < 5 ms | MC-13 |
| 力控带宽 | > 100 Hz | 需求指标 |
| 通信协议 | EtherCAT | SW-01 |
| 供电 | 48V / 5A / 250W | EL-02 |
| 反射库 | 接触/防滑/柔顺反射，板载实时运行 | MC-06 |
| OTA升级 | 支持断点续传、回滚 | SW-02 |

### 1.2 计算量估算

单只灵巧手（11自由度）满载计算量：

| 任务 | 周期 | 单次运算量 | 总算力需求 |
|------|------|-----------|-----------|
| FOC 电流环 × 11 电机 | 100 μs (10kHz) | ~2K FLOPs | ~22 MFLOPs |
| 速度环 PID × 11 | 500 μs (2kHz) | ~500 FLOPs | ~11 MFLOPs |
| 位置环 PID + 轨迹 | 1 ms (1kHz) | ~2K FLOPs | ~44 MFLOPs |
| 反射库（接触+防滑+柔顺） | 1 ms (1kHz) | ~10K FLOPs | ~220 MFLOPs |
| 力位混合控制 | 2 ms (500Hz) | ~20K FLOPs | ~220 MFLOPs |
| EtherCAT 主栈处理 | 1 ms (1kHz) | ~5K FLOPs | ~110 MFLOPs |
| 传感器融合（力+位置） | 1 ms (1kHz) | ~5K FLOPs | ~110 MFLOPs |
| **实时控制总计** | | | **~737 MFLOPs** |
| 前馈/MPC 预测模型 | 10 ms (100Hz) | ~100K FLOPs | ~330 MFLOPs |
| 手势库回放 + 任务调度 | 10 ms | ~20K FLOPs | ~66 MFLOPs |
| **非实时任务总计** | | | **~396 MFLOPs** |
| **合计** | | | **~1.1 GFLOPs** |

**结论：实时部分 < 1 GFLOPs，MCU 可承担；非实时部分 400 MFLOPs，MCU 或轻量 MPU 均可。**

## 二、处理器选型方案对比

### 方案总览

采用 **异构双核架构**：实时 MCU + 非实时 MPU

```
┌─────────────────────────────────────────────────┐
│              灵巧手控制器 PCB                     │
├─────────────────────┬───────────────────────────┤
│  实时域 (Hard RT)    │   非实时域 (Soft RT)       │
│                     │                           │
│  ┌───────────────┐  │  ┌───────────────┐        │
│  │  MCU           │  │  │  MPU / SoC    │        │
│  │  ARM Cortex-M  │  │  │  ARM Cortex-A │        │
│  │  480+ MHz      │  │  │  1+ GHz       │        │
│  │  FreeRTOS      │  │  │  Linux/RT_PREEMPT│     │
│  └───────────────┘  │  └───────────────┘        │
│                     │                           │
│  • FOC 电流环       │  • MPC / 前馈预测         │
│  • 速度/位置环      │  • 手势库 + 任务调度       │
│  • 反射库           │  • EtherCAT 主栈(可选)     │
│  • EtherCAT 从栈    │  • 多模态感知融合          │
│  • 传感器采集       │  • OTA / 通信 / 诊断       │
│  • 安全看门狗       │  • ROS2 桥接              │
└─────────────────────┴───────────────────────────┘
         SPI / 共享DMA / RPMsg 高速互联
```

### 2.1 实时域 MCU 选型

| 评估维度 | STM32H743 | STM32H753 | i.MX RT1170 | ESP32-S3 |
|---------|-----------|-----------|-------------|----------|
| 内核 | Cortex-M7 480MHz | Cortex-M7 480MHz | Cortex-M7 600MHz ×2 | Xtensa/Xtensa 240MHz ×2 |
| 算力 | 1600 DMIPS | 1600 DMIPS | 2100 DMIPS ×2 | ~600 DMIPS ×2 |
| FPU | FPv5-SP | FPv5-SP | FPv5-SP | 无硬件FPU |
| 闪存 | 2MB Flash | 4MB Flash | 6MB Octal RAM | 4MB Flash |
| SRAM | 1MB | 1MB | 1MB TCM + 5MB OCRAM | 512KB |
| ADC | 3×12bit | 3×12bit | 4×12bit | 2×12bit |
| PWM | 16通道 | 16通道 | 16通道 | 8通道 |
| EtherCAT | 需外部ESC | 需外部ESC | 需外部ESC | 需外部ESC |
| 成本 | ~$8 | ~$10 | ~$12 | ~$3 |
| 生态 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ |

**推荐：STM32H753（4MB Flash + 1MB SRAM + FPU + 成熟生态）**

选型理由：
1. **算力足够**：1600 DMIPS >> 737 MFLOPs 实时需求，余量 > 2 倍
2. **FPU 硬件浮点**：FOC 和 PID 计算全靠浮点，必须有 FPU
3. **Flash + SRAM 充足**：4MB Flash 存固件+OTA B分区，1MB SRAM 跑 FreeRTOS 多任务
4. **PWM 通道够**：16 通道 PWM 驱动 11 电机 FOC 有余量
5. **ADC 够**：3 组 12 位 ADC，可并行采样 11 电机编码器 + 电流
6. **生态成熟**：ST 提供完整 HAL、FreeRTOS 移植、EtherCAT CoE 参考

### 2.2 非实时域 MPU/SoC 选型

| 评估维度 | i.MX8M Mini | STM32MP157 | ESP32-S3 | Raspberry Pi Zero 2W |
|---------|-------------|------------|----------|---------------------|
| 内核 | Cortex-A53 1.2GHz | Cortex-A7 650MHz ×2 | Xtensa 240MHz ×2 | Cortex-A53 1GHz ×4 |
| 算力 | ~4000 DMIPS | ~2000 DMIPS ×2 | ~1200 DMIPS | ~8000 DMIPS |
| 内存 | 外部 DDR，最高 2GB | 外部 DDR，最高 1GB | 内部 512KB | 外部 LPDDR，512MB |
| 系统 | Linux / RT_PREEMPT | Linux / A-Sync | FreeRTOS | Linux |
| NPU/AI | 无 | 无 | 无 | 无 |
| 成本 | ~$15 | ~$12 | ~$3 | ~$10 |
| 功耗 | 1-3W | 0.5-2W | 0.3-0.5W | 1-2W |
| 尺寸 | 5×5mm WLCSP | 6×6mm WLCSP | 4×4mm QFN | 模块级 |
| 生态 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

**推荐：STM32MP157（双核 A7 + A-Sync 技术 + 低功耗）**

选型理由：
1. **A-Sync 架构**：STM32 独有的双系统架构，M4 核可独立运行 RTOS，A7 核跑 Linux，天然适配异构需求
2. **低功耗**：0.5-2W，灵巧手供电预算紧张（250W 峰值，但大部分是电机功耗）
3. **小尺寸**：6×6mm WLCSP，适合灵巧手紧凑 PCB
4. **与 MCU 同生态**：如果最终采用 STM32MP157，甚至可以把 MCU 和 MPU 合并为单芯片

### 2.3 精简方案（单芯片）

如果灵巧手空间/成本极度受限，可采用 STM32MP157 单芯片：
- M4 核（Cortex-M4, 200MHz）→ 实时域：FOC + PID + 反射库 + EtherCAT
- A7 核（Cortex-A7, 650MHz ×2）→ 非实时域：MPC + 手势库 + 通信 + OTA

**优点**：BOM 减少、PCB 面积减小、功耗降低、无需芯片间通信
**缺点**：M4 核算力（200MHz）比 H753（480MHz）低，FOC 余量较小

## 三、最终推荐方案

### 方案 A：双芯片方案（推荐 — 性能最优）

| 项目 | 选型 |
|------|------|
| 实时 MCU | **STM32H753VBT6**（Cortex-M7 480MHz, 4MB Flash, 1MB SRAM） |
| 非实时 MPU | **STM32MP157FAA**（Cortex-A7 650MHz ×2 + Cortex-M4 200MHz） |
| 互联 | SPI 全双工 54MHz / 共享 DDR / RPMsg |
| EtherCAT | MCU 侧外挂 ESC（如 EMCDISC7NP） |
| 估算成本 | MCU $10 + MPU $12 + ESC $2 = ~$24/只手 |

### 方案 B：单芯片方案（推荐 — 成本/空间最优）

| 项目 | 选型 |
|------|------|
| 主控 SoC | **STM32MP157FAA**（A7×2 + M4，A-Sync 双系统） |
| M4 核职责 | FOC + PID + 反射库 + EtherCAT 从栈 + 传感器采集 |
| A7 核职责 | MPC + 手势库 + 通信协议 + OTA + ROS2 bridge |
| EtherCAT | SoC 侧外挂 ESC（如 EMCDISC7NP） |
| 估算成本 | SoC $12 + ESC $2 = ~$14/只手 |

### 方案 C：极致低成本方案

| 项目 | 选型 |
|------|------|
| 主控 MCU | **STM32H753VBT6** 单芯片 |
| 职责 | 所有任务（FOC + PID + 反射 + MPC + 通信） |
| 限制 | 无 Linux / ROS2，上位通信走简单串口/USB 协议 |
| 估算成本 | MCU $10 + ESC $2 = ~$12/只手 |

| 维度 | 方案A（双芯片） | 方案B（单芯片A-Sync） | 方案C（单MCU） |
|------|----------------|---------------------|---------------|

| 开发复杂度 | 高 | 中 | 低 |

| OTA 灵活性 | 高 | 中 | 低 |

### 推荐路径

- **工程验证阶段**：方案 C（STM32H753 单 MCU），快速验证算法和硬件
- **产品化阶段**：方案 B（STM32MP157 A-Sync），兼顾性能和成本
- **旗舰版本**：方案 A（H753 + MP157），极致性能

## 五、引脚与外设资源分配（以 STM32H753 为例）

### 5.1 PWM 分配（16 通道）

| 通道 | 用途 | 电机 |
|------|------|------|
| TIM1 CH1-3 | FOC Phase A/B/C | 拇指电机 1-3（如用无刷）|
| TIM8 CH1-3 | FOC Phase A/B/C | 食指电机 |
| TIM8 CH4 | 状态 LED PWM | 指示灯 |
| TIM3 CH1-2 | FOC / 步进 | 中指电机 |
| TIM3 CH3-4 | FOC / 步进 | 无名指电机 |
| TIM4 CH1-2 | FOC / 步进 | 小指电机 |
| TIM4 CH3-4 | 预留 | 腕部电机（如有）|
| TIM5 CH1-4 | 预留 | 扩展/调试 |

> 注：如果采用有刷直流电机+减速器，每电机只需 1-2 路 PWM + H 桥驱动，通道更充裕

### 5.2 ADC 分配（3 组 × 16 通道）

| ADC 组 | 采样对象 | 通道数 |
|--------|---------|--------|
| ADC1 | 11 电机编码器位置 | 11 通道 |
| ADC2 | 11 电机相电流采样 | 11 通道（复用 TIM 触发）|
| ADC3 | 六维力传感器 + 触觉 | 6-12 通道 |

> 使用 DMA 循环模式，ADC1/2/3 交替采样，实现 ≥1kHz 全量采样

### 5.3 通信接口

| 接口 | 用途 |
|------|------|
| ETH + ESC | EtherCAT 主通信 |
| UART1 | 调试串口 |
| UART2 | 传感器串口（如六维力）|
| SPI1 | MCU ↔ MPU 高速互联 |
| SPI2 | Flash / 传感器 |
| I2C1 | 六维力传感器 / 触觉传感器 |
| I2C2 | EEPROM（参数存储）|
| USB FS | 固件升级 / 调试 |
| CAN | 预留（整车 CAN 总线对接）|
