## 一、灵巧手防夹设计

### 需求分解
- **外饰防夹**：灵巧手与人体接触时不造成伤害（夹伤/压伤）
- **内部防夹**：线束不被运动机构夹断、关节间不发生机械干涉

### 硬件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **关节力矩感知** | 每个自由度集成空心杯电机+编码器+应变式力矩传感器 | 参考 Digit/HandyTech 方案，分辨率 ≤0.01Nm |
| **指尖力传感器** | FlexiForce 或压电薄膜（FSR），每指尖 1-2 个 | 接触力阈值触发，响应 <10ms |
| **柔性外覆材料** | 硅胶/TPU 软胶包覆，邵氏硬度 20-40A | 降低接触压强，参考 Soft Robotics 方案 |
| **最大输出力矩限制** | 机械离合/扭矩限制器（可选） | 硬件级最终保护，设定值略高于软件阈值 |
| **线束防护** | 拖链/弹簧护套 + 线束走向避让运动包络线 | 参考 KUKA LBR 线束管理，弯曲半径 ≥3×线径 |
| **线束状态监测** | 线束集成应变传感器或电阻式断裂检测 | 串联检测电阻，断路即报警 |
| **干涉检测** | CAD 运动学仿真 + 物理限位块 | 设计阶段 DFM 验证，关键部位加物理挡块 |

### 软件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **阻抗控制（Impedance Control）** | 末端阻抗 Z = M·s² + D·s + K，可调刚度 | 参考 Franka Emika 方案，接触时自动降刚度 |
| **力矩阈值保护** | 关节力矩 > 阈值 → 降速/停止，分级响应 | 阈值按 ISO/TS 15066：人机协作 ≤1500N（手） |
| **碰撞检测算法** | 观测器法（Observer-based）：估计力矩 vs 实际力矩差值 | 参考 Universal Robots 的 collision sensitivity 算法 |
| **力控闭环** | 力/位混合控制，接触模式下力控优先 | 参考 MIT-Manus 康复机器人方案 |
| **最大接触力限制** | 指尖力 > 10N → 立即停止该关节 | ISO/TS 15066 人体接触限值 |
| **线束状态监控** | 周期检测线束电阻，异常上报 | 100ms 周期巡检 |

### 行业参考
- **Franka Emika**：阻抗控制 + 14 关节力矩传感器，碰撞检测 <1Nm
- **Robotiq 2F-85/140**：力控夹爪，自适应抓取力
- **Shadow Hand / Digit**：每指 4 自由度 + 腱驱动，力传感器反馈
- **ISO/TS 15066**：规定协作机器人力/功率限值，手部接触力 ≤1500N，压强 ≤1.5N/mm²

## 二、基础保护（限位、过载、过压、欠压）

### 硬件方案

| 保护类型 | 硬件实现 | 说明 |
|----------|----------|------|
| **硬件限位** | 磁编码器硬限位 + 机械止动块 | 双冗余：电子限位先于机械限位触发 |
| **过流保护** | MOSFET 驱动 IC 内置过流关断（如 ODrive 方案） | 响应 <100μs，硬件级不可绕过 |
| **过压保护** | TVS 二极管 + 齐纳钳位 + 硬件比较器 | 超过阈值直接切断功率级 |
| **欠压保护** | 电压分压 + ADC 采样 + 比较器 | 低于阈值切断输出，防止 Brown-out |
| **过温保护** | NTC 热敏电阻（电机绕组/驱动器） + 硬件比较器 | 超过 120°C 硬件关断 |
| **保险丝/PTC** | 每路电机独立自恢复保险丝 | 最后一道防线 |

### 软件方案

| 保护类型 | 软件实现 | 说明 |
|----------|----------|------|
| **软件限位** | 关节角度软件限位（Soft Limit） | 比硬件限位提前 5-10° 触发减速 |
| **速度/加速度限制** | 梯形 S 曲线规划，限制最大速度和加加速度 | 防止突变冲击 |
| **过载保护** | 电流积分（I²t 热模型），超过热容量降额 | 参考 IEC 60947 热模型 |
| **电压监控** | ADC 采样母线电压，看窗口 [Vmin, Vmax] | 超限 → 停机 + 故障码上报 |
| **欠压锁定（UVLO）** | 软件层 UVLO 状态机 | 欠压后必须人工/上位机复位 |
| **看门狗** | 独立看门狗 IWDG + 窗口看门狗 WWDG | 软件死锁 → 硬件复位 |

### 保护分级响应表

| 等级 | 条件 | 响应 | 恢复方式 |
|------|------|------|----------|
| L1 警告 | 接近限位/轻度过载 | 降速 + 日志记录 | 自动恢复 |
| L2 降额 | 持续过载/温度偏高 | 降功率运行 + 告警上报 | 条件恢复 |
| L3 停机 | 超限/过流/过压 | 切断输出 + 故障码 | 需复位 |
| L4 锁死 | 严重故障/硬件保护触发 | 硬件关断 + 故障锁定 | 需人工干预 |

## 三、整机姿态安全保护

### 需求分解
- **摔倒识别**：检测到机体摔倒后快速停机
- **防碰撞**：预测并避免与环境/人体的碰撞

### 硬件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **IMU（惯性测量单元）** | 6 轴或 9 轴 IMU，集成于躯干/头部/四肢 | 推荐 BMI088 或 ICM-42688，1kHz 采样 |
| **ToF 深度传感器** | 胸部/头部各 1 个（如 VL53L5CX） | 检测前方障碍物，范围 4-8m |
| **超声波传感器** | 腰部/膝盖布置 | 低成本近距离检测 |
| **接触式碰撞检测** | 关节力矩传感器异常检测（复用需求一） | 碰撞 → 力矩突变 |
| **急停按钮** | 物理急停（E-Stop），硬线连接到安全继电器 | 符合 ISO 13850 要求 |
| **安全继电器/安全 PLC** | 独立安全回路处理急停/安全信号 | 符合 ISO 13849 PLd 以上 |

### 软件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **姿态估计** | IMU + 关节编码器 → 扩展卡尔曼滤波（EKF） | 实时估计机体姿态角 |
| **摔倒检测算法** | 多阈值 FSM：倾斜角 > 60° 且角速度 > 阈值 → 判定摔倒 | 参考 Boston Dynamics Spot 方案 |
| **摔倒响应** | 检测摔倒 → 关节松弛（Zero Effort） + 切断动力 | 防止二次伤害 |
| **碰撞预测** | ToF 数据 + 运动学 → 预测碰撞时间 TTC（Time to Collision） | TTC < 1s 减速，TTC < 0.3s 停止 |
| **安全区域管理** | 定义安全操作空间，超限告警 | 类似机器人围栏概念 |
| **安全状态机** | 正常 → 预警 → 减速 → 停止 → 锁定，逐级升级 | 状态转换条件明确可配置 |

### 摔倒检测算法流程

```
IMU 数据(1kHz)
    ↓
姿态解算（互补滤波/Madgwick）
    ↓
判断条件（同时满足）：
  1. 躯干倾斜角 > θ_th（约 45-60°）
  2. 角速度峰值 > ω_th（约 200-500°/s）
  3. 持续时长 > t_th（约 50-200ms）
    ↓
摔倒确认 → 触发安全响应
  - 所有关节 Zero Torque
  - 切断动力输出
  - 上报摔倒故障码
  - 等待人工复位
```

### 行业参考
- **Boston Dynamics Spot**：IMU + 力控 + 视觉融合，摔倒后可自主恢复
- **Unitree H1/G1**：全身力控 + 跌倒检测
- **ISO 13850**：急停装置设计要求
- **ISO 13849**：安全控制系统设计，PL 等级评估

## 四、功能安全 — 故障上报

### 需求分解
能够上报以下故障：
- 堵转
- 过温
- 过流
- 电压异常（过压/欠压）
- 电机其他异常
- 通信异常

### 硬件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **安全 MCU / 双核锁定** | ARM Cortex-M 双核锁步（如 STM32H7 系列）或独立安全 MCU | 检测软件跑飞 |
| **隔离电路** | 数字隔离器（如 ISO7741）隔离安全信号 | 防止共模干扰 |
| **独立电源监测** | 独立于主控的电压监控 IC（如 ADM1177） | 主控失效时仍能上报 |
| **安全通信通道** | 故障信号通过独立通道（如 CAN FD 独立消息 ID）上报 | 与正常控制通道隔离 |
| **硬件故障标志** | 关键信号锁存故障状态，断电不丢失（EEPROM/Flash） | 故障追溯 |

### 软件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **故障诊断状态机** | 每个故障类型独立诊断任务，周期运行 | 参考 PLCopen 运动控制规范 |
| **故障码体系** | 统一故障码定义：类别(1字节) + 代码(2字节) + 严重度(1字节) + 时间戳 | 便于追溯和解析 |
| **故障上报协议** | CAN FD / Ethernet（SOEM/ADS）上报，含故障码 + 原始数据快照 | 支持实时和记录两种模式 |
| **故障优先级** | 致命 > 严重 > 警告 > 信息，高优先级抢占上报 | 防止故障淹没 |
| **故障去抖** | 连续 N 个周期确认后才上报（防止误报） | 可配置去抖参数 |
| **故障日志** | 环形缓冲区记录最近 N 条故障，掉电保存 | 便于售后诊断 |
| **心跳机制** | 节点间心跳，超时判定通信异常 | 心跳周期 10-50ms |

### 故障码定义示例

| 故障类别 | 代码 | 描述 | 严重度 | 响应 |
|----------|------|------|--------|------|
| 电机故障 | 0x0101 | 堵转 | 严重 | 停机 |
| 电机故障 | 0x0102 | 过温 | 严重 | 降额/停机 |
| 电机故障 | 0x0103 | 过流 | 致命 | 立即切断 |
| 电机故障 | 0x0104 | 编码器异常 | 严重 | 停机 |
| 电压故障 | 0x0201 | 过压 | 致命 | 立即切断 |
| 电压故障 | 0x0202 | 欠压 | 严重 | 停机 |
| 通信故障 | 0x0301 | CAN 总线离线 | 严重 | 停机 |
| 通信故障 | 0x0302 | 心跳超时 | 严重 | 停机 |
| 通信故障 | 0x0303 | 数据校验错误 | 警告 | 重试/告警 |
| 安全故障 | 0x0401 | 急停触发 | 致命 | 立即切断 |
| 安全故障 | 0x0402 | 摔倒检测 | 致命 | 关节松弛 |
| 安全故障 | 0x0403 | 碰撞检测 | 严重 | 停止 |

### 行业参考
- **ISO 13849**：安全控制系统，PL（Performance Level）评估
- **IEC 61508**：功能安全通用标准
- **PLCopen**：运动控制故障处理规范
- **ODrive 开源项目**：完善的故障检测和上报机制

## 五、电气安全合规

### 标准适用性分析

| 标准 | 适用范围 | 机器人适用性分析 |
|------|----------|----------------|
| **IEC 60335-1:2020** | 家用电器电气安全 | 部分适用：电池安全、绝缘、接地等通用条款可参考 |
| **IEC 60034-1:2026** | 旋转电机 | 电机本体需满足：绝缘等级、温升、防护等级等 |
| **IEC 60204-1** | 机械电气设备 | **更适用**：机器人整机电气安全 |
| **ISO 13849** | 安全控制系统 | 安全功能设计依据 |
| **IEC 61000 系列** | EMC | 电磁兼容性 |

### 硬件方案

| 项目 | IEC 60335-1 要求 | 实现方案 | 说明 |
|------|-----------------|----------|------|
| **防触电保护** | Class I/II 防护 | 绝缘 + 保护接地（Class I） | 接地电阻要求豁免 |
| **绝缘电阻** | ≥ 2MΩ（基本绝缘） | PCB 爬电距离/电气间隙设计 | 按额定电压确定间距 |
| **耐压测试** | 1000-1500V AC / 1min | 设计余量 2000V AC | 实测验证 |
| **接地连续性** | ≤ 0.1Ω | 金属结构件可靠接地 | 接地电阻豁免但仍建议做好 |
| **电池安全** | 过充/过放/过流保护 | BMS 三级保护 | 参考 UL 2054 / IEC 62133 |
| **温升限制** | 可触及表面 ≤ 70°C | 热设计 + 软件限温 | 实测验证 |
| **结构安全** | 机械强度 | 关键结构件强度计算 | 参考 ISO 12100 |

| 项目 | IEC 60034-1:2026 要求 | 实现方案 | 说明 |
|------|----------------------|----------|------|
| **绝缘等级** | F 级（155°C）或 H 级（180°C） | 电机绕组绝缘材料选择 | 温升限值按等级 |
| **防护等级** | IP 等级定义 | 空心杯电机通常 IP20-IP34 | 按使用环境确定 |
| **振动/噪声** | 振动速度限值 | 动平衡 + 减震设计 | 实测验证 |
| **额定数据** | 铭牌标注 | 标称电压/电流/功率/转速 | 按实测值标注 |

### EMC 方案（IEC 61000 系列）

| 项目 | 方案 | 说明 |
|------|------|------|
| **滤波** | 输入端 EMI 滤波器（X/Y 电容 + 共模电感） | 抑制传导干扰 |
| **屏蔽** | 电机线用屏蔽线，良好接地 | 抑制辐射干扰 |
| **PCB 设计** | 接地平面、分割敏感区、去耦电容 | 从设计源头控制 |
| **TVS/浪涌** | I/O 口 TVS 保护 | 抗 ESD 和浪涌 |

### 软件方案

| 项目 | 方案 | 说明 |
|------|------|------|
| **上电自检（POST）** | 启动时自检：电压、传感器、通信、存储器 | 自检通过才允许运行 |
| **持续自检** | 运行时周期性自检关键安全参数 | 100ms 周期 |
| **合规数据记录** | 记录绝缘电阻、温升等合规相关数据 | 用于认证测试追溯 |
| **固件版本管理** | 记录固件版本、配置参数 | 认证一致性 |

### 实测验证项目清单

| 序号 | 测试项目 | 依据标准 | 判定准则 |
|------|----------|----------|----------|
| 1 | 绝缘电阻测试 | IEC 60335-1 §11 | ≥ 2MΩ |
| 2 | 耐压测试 | IEC 60335-1 §11 | 1000V AC / 1min 无击穿 |
| 3 | 接地连续性 | IEC 60335-1 §9 | 豁免，但建议 ≤ 0.1Ω |
| 4 | 温升测试 | IEC 60034-1 | 不超过绝缘等级限值 |
| 5 | 电池安全 | IEC 62133 | 过充/过放/短路无起火 |
| 6 | EMC 传导 | IEC 61000-4-6 | 通过 |
| 7 | EMC 辐射 | IEC 61000-4-3 | 通过 |
| 8 | ESD | IEC 61000-4-2 | 接触 ±6kV / 空气 ±8kV |
| 9 | 浪涌 | IEC 61000-4-5 | ±1kV/±2kV |

## 关键建议

1. **安全等级评估**：按照 ISO 13849 进行风险评估，确定各安全功能的 PL 等级要求
2. **冗余设计**：关键安全功能采用硬件+软件双重保护，硬件级保护不可绕过
3. **模块化**：各关节/节点独立安全保护，单点故障不影响全局
4. **认证路径**：整机建议走 IEC 60204-1 + ISO 13849 认证路线，IEC 60335-1 作为参考
5. **实测优先**：如需求所述"按照实测为准"，所有限值参数以实测数据为基础设定
6. **故障追溯**：完善的故障码体系和日志记录，便于问题定位和售后诊断
7. **渐进式实现**：先实现 L1-L2 硬件和驱动层保护，再逐步完善 L3-L4 高层安全功能
