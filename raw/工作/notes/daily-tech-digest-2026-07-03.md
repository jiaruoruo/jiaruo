## 🤖 一、AI 智能领域

### 1. Anthropic Claude Sonnet 5 发布，定价极具侵略性
- Anthropic 发布 Claude Sonnet 5，号称"最 Agent 化的 Sonnet 模型"，可作为 Free/Pro 计划默认模型
- API 首发价 $2/M tokens (input) / $10/M tokens (output) 至 8 月 31 日，之后涨至 $3/$15，远低于顶级 Opus 4.8 的 $5/$25
- 公司正加速推进 IPO
- 来源: VentureBeat

- 79% 的企业已支付过 AI Agent "失控"造成的损失
- 来源: VentureBeat

- 解决 AI Agent 面对成千上万个工具时的路由问题
- 不再加载所有工具，而是智能选择，大幅降低 Token 成本
- 来源: VentureBeat

### 4. 美团开源 LongCat-2.0，1.6T 参数全中国芯片训练
- 近前沿 Agent 编程模型，已在 OpenRouter 上领先
- 采用 MIT 开源协议，支持企业集成

### 5. Z.ai 推出 ZCode 挑战 Cursor/Claude Code/Copilot

- 来源: VentureBeat

### 6. Google 25 年来首次重新设计搜索框
- 7 月正式弃用传统搜索框范式，转向 AI 对话交互
- 来源: VentureBeat

### 7. Google Gemini Omni Flash 上线 API
- 首个 Gemini Omni 系列模型，支持通过自然语言生成、修改和编辑视频
- 可取代需要剧组、剪辑师的多工具视频制作流水线
- 来源: VentureBeat

### 8. Google Gemini 3.1 Flash-Lite（Nano Banana 2 Lite）
- 低成本、4 秒快速企业级图像生成

- 来源: VentureBeat

### 9. Microsoft 泄露 "Copilot OS" (Aion) 概念
- 轻量化 Windows OS 概念，完全围绕 Copilot 和 Agentic AI 构建
- Chrome OS 风格，基于 Edge 浏览器和 Web 应用
- 可能关联 Project Solara
- 来源: The Verge

### 10. Cloudflare 将封杀"多用途"爬虫
- 9 月 15 日起，禁止同时用于搜索索引和 AI 训练的爬虫
- 目标是让 AI 公司分离不同用途的爬虫，给发布者更多控制权
- 来源: The Verge

### 11. 摩根士丹利让 Agent 降低自主性来降低风险
- 在风险最高的对账工作中，减少概率性决策，增加固定规则，每项调用需人工签字
- Agent 工作减半，风险可控
- 来源: VentureBeat
