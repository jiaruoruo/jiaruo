## 🔥 一、arXiv 热门论文精选

### ⭐ 域控相关（高优先级）

#### 1. ActiveVision：多模态大模型主动视觉观察基准 ⭐⭐⭐
- **论文**: [2607.16165](https://arxiv.org/abs/2607.16165)
- **方向**: 多模态大模型 / 主动视觉感知
- **亮点**: 提出 17 项任务、3 类分类的 ActiveVision 基准，测试 MLLM 是否具备主动观察能力。GPT-5.5 最高仅 10.6%，Claude Fable 5 仅 3.5%，人类平均 96.1%
- **域控关联**: 主动视觉感知是自动驾驶场景理解的核心能力，当前 MLLM 在此方向严重不足，对车载感知系统的多模态融合有启示意义

#### 2. ATSplat：自适应 3D 高斯溅射 ⭐⭐
- **论文**: [2607.20417](https://arxiv.org/abs/2607.20417)
- **方向**: 3D 重建 / 新视角合成
- **亮点**: 1136 FPS 渲染（512×960），仅需 311K 高斯（减少 5.7×），单 GPU 1 秒内完成 12 图重建
- **域控关联**: 高效 3D 重建对车载 SLAM 和场景理解有参考价值，实时渲染能力可用于车载 HUD/AR

#### 3. G-MAD：多视角红外-可见光空中目标检测数据集 ⭐⭐
- **论文**: [2607.19942](https://arxiv.org/abs/2607.19942) (ACM Multimedia 2026)
- **方向**: 多模态感知 / 红外+可见光检测
- **亮点**: 基于 Arma3 引擎生成大规模多视角 RGB-T 数据集，开源可用
- **域控关联**: 多模态融合（可见光+红外）是车载感知在恶劣天气/夜间场景的补充方向

### 🤖 机器人 / 具身智能

#### 4. Anchor-Align：VLA 通用性微调新方法 ⭐⭐⭐
- **论文**: [2607.13429](https://arxiv.org/abs/2607.13429)
- **方向**: 视觉-语言-动作 (VLA) 微调
- **亮点**: 物理 xArm7 机器人上成功率从 28%→54% 和 37%→60%，通过表征锚定+语言-动作对齐解决 BC 微调导致的表征退化
- **点评**: 对具身机器人的泛化能力有实质性提升，与理想机器人的技术方向相关

#### 5. SeededGrasp：多形态复杂场景语言引导抓取 ⭐⭐
- **论文**: [2607.20207](https://arxiv.org/abs/2607.20207)
- **方向**: 机器人抓取 / 多形态支持
- **亮点**: VLM 提供语义种子点 + 轻量几何生成器，仿真成功率 72%，真实环境 78%，首个多形态桌面抓取数据集（250 万抓取）
- **点评**: 解耦语义推理和几何执行是抓取领域的有效思路

### 🧠 推理 / 优化 / RL

#### 6. RIPO：黎曼等距策略优化（ICML 2026）⭐⭐⭐
- **论文**: [2607.10169](https://arxiv.org/abs/2607.10169)
- **方向**: LLM 强化学习 / 探索崩溃
- **亮点**: 揭示 PPO-Clip 的本质缺陷（欧氏度量与黎曼流形几何不匹配），提出 RIPO 保证黎曼流形上的等距策略更新。AIME24 上比 GRPO 提升 60%
- **点评**: 理论贡献重要，ICML 2026 接收，影响 LLM 推理训练效率

#### 7. SLPO：潜在推理的代理策略优化 ⭐⭐
- **论文**: [2607.19691](https://arxiv.org/abs/2607.19691)
- **方向**: 潜在推理 / RLVR / 测试时扩展
- **亮点**: 首次将可验证奖励 RL 引入自回归潜在推理器，引入代理策略密度和可变长度停止头
- **点评**: 潜在推理（隐空间计算）比显式 CoT 更高效，SLPO 为其打开了 RL 训练路径

#### 8. Hypernetwork 知识注入的缩放定律 ⭐⭐
- **论文**: [2607.19604](https://arxiv.org/abs/2607.19604)
- **方向**: 知识注入 / 超网络 / 缩放定律
- **亮点**: 首次系统研究超网络的缩放行为，构建 MegaWikiQA 数据集（千万级多跳问答），发现超网络在 OOD 泛化上比 LoRA/全量微调有更强的缩放指数
- **点评**: 为 LLM 持续注入新知识提供了原理性方案

### 🎨 视频 / 视觉

#### 9. SGF：自梯度强制长视频外推 ⭐⭐
- **论文**: [2607.20368](https://arxiv.org/abs/2607.20368)
- **方向**: 视频生成 / 自回归扩散
- **亮点**: 两阶段训练恢复历史上下文梯度信号，解决自回归视频生成中的暴露偏差问题

#### 10. 自适应稀疏注意力用于视频生成 ⭐⭐
- **论文**: [2607.16190](https://arxiv.org/abs/2607.16190)
- **方向**: 视频生成 / 稀疏注意力 / 分布式推理
- **亮点**: 运行时负载均衡 + 空闲感知稀疏增强，Wan2.2 I2V 上注意力加速 4.41×，DiT 推理加速 2.02–2.11×

#### 11. Trace：多领域视觉推理强化学习环境 ⭐⭐
- **论文**: [2607.19790](https://arxiv.org/abs/2607.19790)
- **方向**: VLM 强化学习 / 多域视觉推理
- **亮点**: 277 场景语法 + 11 视觉域 + 1000 任务，RLVR 后 Qwen2.5-VL 在 24 个外部基准上平均提升 3.51–4.06 个百分点

### 📝 Agent / 评估 / 可解释性

#### 12. DocOps：自主 Agent 文档操作可验证基准 ⭐⭐
- **论文**: [2607.19865](https://arxiv.org/abs/2607.19865)
- **方向**: Agent 评估 / 文档操作
- **亮点**: 揭示 Agent 三大失败模式：长期状态跟踪崩溃、浅层语义验证、破坏性结构元数据编辑

#### 13. RECAP：可解码激活解释的监督方法 ⭐⭐
- **论文**: [2607.20379](https://arxiv.org/abs/2607.20379)
- **方向**: 可解释性 / AI 安全
- **亮点**: 证明高重建分数不能保证个体声明真实，RECAP 通过辅助预测器保持指定内容可解码，对抗攻击下仍有效（AUC 0.95）

#### 14. 面向 AI Agent 的文档集筛选与排序 ⭐⭐
- **论文**: [2607.19747](https://arxiv.org/abs/2607.19747)
- **方向**: 检索增强 / 文档集评估
- **亮点**: SetwiseEvalKit 三层次九维度评估基准，Rubric4Setwise 方法用更少的文档和检索轮次实现最优下游生成

#### 15. Diff-Logic：边缘设备上的可微逻辑门网络（CAAI 2026）⭐⭐
- **论文**: [2607.18149](https://arxiv.org/abs/2607.18149)
- **方向**: 边缘 AI / 逻辑神经网络 / BCI
- **亮点**: 将模型编译为纯布尔电路，Jetson Orin Nano 上推理时间不随规模增长，峰值加速 2.9×
- **域控关联**: 边缘端低功耗推理架构对车载嵌入式 AI 芯片设计有参考价值
