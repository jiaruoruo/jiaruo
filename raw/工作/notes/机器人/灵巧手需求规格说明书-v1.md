## 一、运动控制需求

| ID | 需求描述 | 指标/约束 | 优先级 |
|----|---------|-----------|--------|
| MC-01 | 运动超限检查与急停 | 检测到超限立即停止运动 | P0 |
| MC-02 | 位置环控制 | 支持位置闭环控制模式 | P0 |
| MC-03 | 速度环控制 | 支持速度闭环控制模式 | P0 |
| MC-04 | 运动平顺性 | 手指转动自然、顺滑，无卡顿 | P0 |
| MC-05 | 宏微协同控制 | 高层规划与低层控制分离；小脑算法具备前馈控制和预测模型控制 | P0 |
| MC-06 | 反射库 | 小脑具备反射库（接触反射、防滑反射、柔顺抓握反射），定义每种反射的触发条件（来源传感器、阈值）和响应策略（力/位置调整策略） | P0 |
| MC-07 | 双手协同作业 | 双手可感知相对位置和力，实现协同作业能力 | P1 |
| MC-08 | 臂手一体协同控制 | 具备臂手一体协同控制算法 | P1 |
| MC-09 | 操控频率 | > 1 kHz | P0 |
| MC-10 | 响应速度 | < 10 ms | P0 |
| MC-11 | 传感器采样频率 | 位置、力矩传感器采样 ≥ 1 kHz | P0 |
| MC-12 | 指令下达延迟 | 接收控制信号 → 手指动作启动 < 5 ms | P0 |
| MC-13 | 感知反馈延迟 | 触觉/力觉传感器 → 控制算法处理 < 5 ms | P0 |
| MC-14 | 闭环控制周期 | 指令 → 动作 → 反馈 → 修正 < 2 ms | P0 |

## 二、状态指示灯需求

| ID | 需求描述 | 指标/约束 | 优先级 |
|----|---------|-----------|--------|
| IND-01 | 灯语功能 | 电源指示、运行状态指示、通信状态指示、故障报警指示，采用不同颜色灯语 | P1 |
| IND-02 | 颜色方案 | 绿色=正常；黄色=警告/待机；红色=故障；蓝色=通信/功能状态 | P1 |
| IND-03 | 显示模式 | 支持常亮、慢闪、快闪等方式区分状态 | P2 |
| IND-04 | 布局要求 | 位置便于观察，不影响灵巧手结构紧凑性 | P2 |

## 附录：需求指标汇总

### 时序指标（关键路径）

| 指标 | 要求 | 备注 |
|------|------|------|
| 操控频率 | > 1 kHz | 即周期 ≤ 1 ms |
| 传感器采样 | ≥ 1 kHz | 位置 + 力矩 |
| 指令延迟 | < 5 ms | 接收→启动 |
| 感知延迟 | < 5 ms | 传感→算法 |
| 闭环周期 | < 2 ms | 指令→动作→反馈→修正 |
| 响应速度 | < 10 ms | 端到端 |
| 力控带宽 | > 100 Hz | 即周期 ≤ 10 ms |

### 安全标准

- IEC 60335-1:2020（家电安全，接地电阻豁免）
- IEC 60034-1:2026（旋转电机）
