Windows SOEM EtherCAT 主站 — 周期通信数据包统计

基于 SOEM 2.0 源码分析，统计主站软件在不同阶段（初始化、周期运行、故障恢复）发送的全部 EtherCAT 数据报类型，附完整帧格式字段说明。

LRW 特性
主站发送时 Data 填写输出 PDO；帧经过每个从站时，从站将自身输出寄存器写入对应逻辑地址， 并把输入寄存器覆盖写回帧内同一 Data 区域，实现单帧双向传输。WKC 预期值 = Σ(输出WKC×2 + 输入WKC×1)。

DC 延迟测量原理
BWR 触发后，每个从站在自身端口记录该帧的精确接收时刻（DCrecvTimeA/B/C/D）， 主站随后通过 FPRD 逐一读回这些时刻，计算出各段传播延迟，用于补偿 FRMW 同步误差。

自增地址原理
帧从主站出发时 ADP=0，每经过一个从站 ADP 递减 1。当 ADP=0 时该从站响应， 其余从站忽略。SOEM 以此枚举 0、−1、−2… 位置的从站，完成拓扑发现后用 APWR 写入固定地址。

4周期通信（OP 状态，每 1 ms）

每周期实际发送的帧构成
正常 OP 运行时，ecx_send_processdata() 每次构造 1 个以太网帧， 其中包含 LRW 数据报（携带所有组的 PDO 数据）， 若启用了分布式时钟（DC）则在同一帧尾追加 FRMW 数据报（M=1 链接）。
帧内数据报CmdData 大小WKC 期望发送函数频率
LRW 过程数据 0x0C = IO Map 大小（典型 8–512 B） Σ(outputsWKC×2 + inputsWKC) ecx_send_processdata 每周期 1 次
FRMW DC 同步（可选） 0x0E 8 B（int64 时间戳） 从站数 ecx_send_processdata（内部判断） 每周期 1 次（DC 使能时）
状态轮询 FPRD 0x04 2 B (AL Status) 1 ecx_readstate（每1万周期调用一次） 低频（周期/10000）

周期帧在总线上的时序（以 1 ms 周期、2 个从站为例）

t=0.000ms ▶ ETH Frame 发出 [DA=FF:FF:FF:FF:FF:FF | EType=88A4 | LRW(Output PDO) | FRMW(DC时间)]
t=0.001ms ↘ 从站#1 处理 LRW 写入自身输出寄存器，将输入寄存器覆盖回帧，WKC+=3
t=0.002ms ↘ 从站#2 处理 LRW 同上，WKC+=3，帧继续向末端传播
t=0.003ms ↩ 末端帧折返回主站
t=0.100ms ◀ ETH Frame 回到主站 NIC [Input PDO 已更新，WKC=6，DC时间已同步]
t=0.100ms ecx_receive_processdata() 返回 wkc=6
t=0.100ms 用户控制逻辑执行（读取 Input PDO，计算，写 Output PDO）
t=1.000ms ▶ 下一周期帧发出 ...

5初始化阶段通信序列

① ecx_init() — 网卡初始化

发送一帧 BRD(ADO=0x0000, Len=2) 探测总线，WKC 返回即为在线从站数。同时为冗余链路准备 BRD 心跳帧。

② ecx_config_init() — 拓扑发现

循环发送 APRD(ADP=0,−1,…, ADO=0x0000 类型) 读取各从站类型信息；然后用 APWR(ADO=0x0010) 写入固定站地址（1001、1002…）；再用 FPRD 读取 EEPROM（SII）获取 VendorID、ProductCode、SM/FMMU 配置等。

③ ecx_config_map_group() — PDO 映射

对每个从站发送 FPWR 配置 FMMU 条目 （物理↔逻辑地址映射）和 SM 条目；若从站支持 CoE 则通过 SDO 邮箱 写 0x1C12/0x1C13 完成 PDO 映射。

④ ecx_configdc() — 分布式时钟

步骤 1: BWR(0x0900) 锁存全网接收时间
步骤 2: ARMW(自增地址) 测量总线传播延迟
步骤 3: FPRD 逐站读回时间戳，计算偏移
步骤 4: FPWR 写系统时间偏移(0x0920) + SYNC0 参数(0x0990/0x09A0) + 激活(0x0981)

⑤ 状态迁移 INIT→PreOP→SafeOP→OP

每次迁移：FPWR(0x0120) 写 AL Control 请求目标状态 → 循环 FPRD(0x0130) 查询 AL Status 直到达到目标状态。

6非周期通信（故障恢复 / SDO 访问）

场景使用命令触发条件说明
从站状态巡检 FPRD ×N 从站 每 10000 个周期（checkAndRecoverSlaves） 读所有从站 AL Status，发现非 OP 状态则触发恢复
从站状态恢复 FPWR 检测到从站退出 OP 时 写 AL Control 重新请求 OP 状态
SDO 读取 ecx_SDOread FPWR（写邮箱）
FPRD（轮询响应）		 应用层调用（初始化或运行时诊断） 通过 SM0/SM1 邮箱传输 CoE SDO 上传请求/响应，超时 EC_TIMEOUTRXM=700ms
SDO 写入 ecx_SDOwrite FPWR × 2 同上 写邮箱 + 确认响应，用于参数配置（速度环增益、限位等）
WKC 不匹配告警 无额外帧 Diagnostics::update() 检测 仅软件统计，不发额外帧；WKC < expectedWKC 说明至少一个从站未响应

7全生命周期通信时序总览

阶段              命令序列

【初始化阶段】
  ecx_init()     → BRD(0x0000, 2B)  ← 探测从站数
  config_init()  → APRD(0,  ECT_REG_TYPE, 2B)    ← 读从站类型
                 → APRD(-1, ECT_REG_TYPE, 2B)
                 → ... × N从站
                 → APWR(0,  ECT_REG_STADR, 2B=1001)  ← 写固定地址
                 → APWR(-1, ECT_REG_STADR, 2B=1002)
                 → FPRD(1001, ECT_REG_EEPSTAT, N B)  ← 读 SII/EEPROM
                 → FPRD(1002, ECT_REG_EEPSTAT, N B)
  config_map()   → FPWR(1001, 0x0600, 16B)  ← 配置 FMMU
                 → FPWR(1001, 0x0800, 8B)   ← 配置 SM
                 → [CoE] FPWR+FPRD  × M   ← SDO 邮箱（PDO 映射）
  configdc()     → BWR (0x0000, 0x0900, 4B)  ← 锁存 DC 时间
                 → ARMW(0, 0x0900, 8B) × 多次  ← 延迟测量
                 → FPRD(each, 0x0900, 8B)       ← 读各站时间
                 → FPWR(each, 0x0920, 8B)       ← 写时间偏移
                 → FPWR(each, 0x0990/0x09A0/0x0981, ...)  ← SYNC0配置
  状态迁移        → FPWR(0, 0x0120, 2B=0x02)   ← → PreOP
                 → FPRD(0, 0x0130, 2B) × poll  ← 等待 PreOP
                 → FPWR(0, 0x0120, 2B=0x04)   ← → SafeOP
                 → FPRD(0, 0x0130, 2B) × poll
                 → LRW (首帧, 空数据)          ← 进入OP前预发
                 → FPWR(0, 0x0120, 2B=0x08)   ← → OP
                 → FPRD(0, 0x0130, 2B) × poll

【周期运行阶段】 （每 1 ms 重复）
  send_pd()      → LRW(LogAddr, IO Map size) [+ FRMW(DC时间, 8B)]
  receive_pd()   ← 同一帧回来，Input PDO 已更新，WKC 已计算
  [每1万周期]    → FPRD(each, 0x0130, 2B)  ← 巡检状态
                 → FPWR(异常站, 0x0120, OP)  ← 恢复异常从站

【SDO 访问（任意时刻，非周期）】
  SDOwrite()     → FPWR(slave, SM0_addr, 6+N B)  ← 写请求邮箱
                 ← FPRD(slave, SM1_addr, 6+N B)  ← 读响应邮箱
  SDOread()      → FPWR(slave, SM0_addr, 6 B)     ← 上传请求
                 ← FPRD(slave, SM1_addr, 6+N B)  ← 读上传数据
