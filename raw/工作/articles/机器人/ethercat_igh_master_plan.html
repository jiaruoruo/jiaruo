EtherCAT IgH 主站搭建方案

面向 Linux 平台的 EtherCAT IgH Master 部署与开发方案，适用于入门验证、设备联调、 自研控制器开发与后续实时化扩展。

方案概述 硬件建议 软件建议 搭建步骤 命令示例 实时化建议 常见问题 实施路径

1. 方案概述

IgH EtherCAT Master 是 Linux 下常见的开源 EtherCAT 主站实现，适合用于：

  • EtherCAT 从站联调
  • IO 模块测试
  • 伺服驱动器通信验证
  • 自研控制器原型开发
  • Linux 实时通信方案构建
Linux IgH EtherCAT Master Intel NIC PREEMPT_RT 可选 ecrt API
推荐起步方案：Ubuntu / Debian + Intel 网卡 + IgH Master + EtherCAT 从站

2. 硬件建议

主机平台

  • x86 PC
  • 工控机
  • 后续可迁移到嵌入式 Linux 平台

网卡建议

  • 优先推荐 Intel 网卡
  • 如 i210 / i211 / i350
  • 尽量使用独立物理网口

从站设备

  • EtherCAT IO 模块
  • 伺服驱动器
  • 从站评估板
  • 远程耦合器
不建议新手一开始使用 USB 网卡、虚拟机网卡或办公网络共用网口。

3. 软件建议

项目 推荐方案 说明
操作系统 Ubuntu 22.04 / Debian Stable 先用普通内核跑通，后续再加实时补丁
主站软件 IgH EtherCAT Master 开源，适合原型开发和工程验证
开发接口 ecrt API 用于应用层进行 PDO/SDO 和周期通信开发
验证工具 ethercat 命令行 用于扫描从站、查看 PDO/SDO、状态诊断
实时化 PREEMPT_RT（可选） 适合后续提升周期稳定性和降低抖动

4. 搭建步骤

4.1 准备 Linux 环境

  • 安装 Ubuntu 或 Debian
  • 准备专用 EtherCAT 网口
  • EtherCAT 从站上电并连接

4.2 安装编译依赖

sudo apt update sudo apt install -y git build-essential autoconf automake libtool pkg-config sudo apt install -y linux-headers-$(uname -r) sudo apt install -y flex bison

4.3 获取 IgH Master 源码

建议固定一个稳定版本，用于后续项目维护和版本一致性控制。

4.4 编译与安装

./bootstrap ./configure --enable-generic make -j$(nproc) sudo make install sudo ldconfig

4.5 配置 EtherCAT 主站

常见配置文件为：

/etc/ethercat.conf

可在配置中指定主站使用的网卡、MAC 地址或驱动绑定方式。

4.6 加载模块并启动服务

sudo modprobe ec_master sudo modprobe ec_generic sudo systemctl start ethercat
某些系统可能使用 /etc/init.d/ethercat start 启动。

5. 常用验证命令

5.1 查看主站状态

ethercat master

5.2 扫描从站

ethercat slaves

5.3 查看从站详细信息

ethercat slaves -v

5.4 查看 PDO / SDO

ethercat pdos ethercat sdos
如果 ethercat slaves 能看到从站，说明主站、网卡和物理连接基本已经打通。

6. 实时化建议

如果项目后续需要更稳定的周期通信，建议逐步引入以下优化：

  • PREEMPT_RT 实时内核
  • EtherCAT 周期线程绑核
  • 关闭 CPU 节能与频率动态调节
  • 专用网口独占，不参与普通网络通信
  • 应用线程使用 SCHED_FIFO 高优先级调度
普通 Linux 内核适合验证与联调；若进行高稳定性 1ms 甚至更低周期控制，建议使用 PREEMPT_RT。

7. 常见问题

7.1 看不到从站

  • 检查从站是否上电
  • 检查网线和拓扑
  • 确认使用的是专用 EtherCAT 网口
  • 确认网卡是否已被 EtherCAT Master 绑定

7.2 编译模块失败

  • 检查内核头文件版本是否匹配
  • 确认当前系统内核版本与编译环境一致
  • 建议固定 Linux 版本和 IgH 版本

7.3 普通网络抢占网卡

  • 不要给 EtherCAT 口配置普通 IP
  • 将该接口从 NetworkManager 管理中排除
  • EtherCAT 口专口专用

7.4 进不了 OP

  • 检查 PDO 映射
  • 检查从站启动要求
  • 伺服设备可能需要 CiA402 状态机控制
  • 检查 DC 配置与同步状态

8. 项目实施路径

阶段 1：环境验证

目标：主站编译通过，命令行可识别从站。

阶段 2：IO 通信

目标：实现简单 PDO 周期收发，验证输入输出。

阶段 3：参数访问

目标：实现 SDO 读取与配置操作。

阶段 4：周期任务

目标：实现固定周期线程，监控抖动与稳定性。

阶段 5：伺服控制

目标：接入 CiA402，使能驱动器并进行运动控制。

阶段 6：实时优化

目标：引入 PREEMPT_RT、绑核和系统优化，形成工程方案。

9. 方案总结

EtherCAT IgH 主站搭建的核心思路是：

Linux + 专用 Intel 网卡 + IgH EtherCAT Master + EtherCAT 从站

在此基础上，通过 ethercat 命令行工具完成从站扫描和诊断， 再通过 ecrt API 开发用户态或实时应用程序。

建议先完成“能扫到从站、能读 PDO/SDO”的基础验证，再逐步推进到实时任务和伺服控制。
