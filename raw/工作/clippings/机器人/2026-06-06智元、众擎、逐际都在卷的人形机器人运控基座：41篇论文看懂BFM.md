# 智元、众擎、逐际都在卷的人形机器人运控基座：41篇论文看懂BFM

作者微信 yzz010329 · 商务微信 jszn576

我原来以为，BFM 主要是在给人形机器人做一个更大的动作库。

**BFM 最值得看的地方，是它把“动作能力”往“身体接口”这一层推。**

VLA 可以理解任务，世界模型可以预测未来，语言模型可以做规划。但这些东西最后都要落到人形机器人的身体上：怎么走过去，怎么保持平衡，怎么起身，怎么接触物体，怎么在扰动之后继续执行。

所以这篇文章比较长，可以把它当成一张 **BFM 技术地图**。这次我会把仓库里列出的 **41 篇论文全部放进来**，按路线讲清楚它们分别在补什么。

项目仓库：https://github.com/friedrichyuan/awesome-bfm-papers

配套综述：A Survey of Behavior Foundation Model: Next-Generation Whole-Body Control System of Humanoid Robots

01写在前面：这 41 篇到底在讲什么

我没有按时间线写，也没有把 41 篇论文堆成一串摘要。更适合 BFM 的读法，是按 **五个问题** 组织：

-   **Forward-backward 表征：能不能把不同任务压进一个可调用的身体潜空间；**
-   **Goal-conditioned 学习：能不能把动作跟踪、全身技能和人-物交互做成大覆盖面的身体能力；**
-   **Intrinsic reward 预训练：没有明确任务时，身体应该先学到哪些可迁移经验；**
-   **Adaptation：预训练出来的 BFM，怎么进入新任务、新动力学和新机器人；**
-   **Hierarchical control：语言、VLA、扩散模型和规划器，怎么调用底层身体。**

我的整体判断是：

**BFM 这条路线正在把人形机器人运动控制，从“技能训练”推向“身体接口工程”。**

把 41 篇放在一起看，它们其实在处理同一件事：**让机器人身体变成上层智能可以复用、适配和调用的底座。** 这里还有一个很现实的产业背景：**智元已经把 BFM-2 直接推成“运控基座模型”，后面还预告了 BFM-3；众擎年度视频里展示的多动作拼接、长时程稳定、倒地起身和抗扰恢复，也明显落在同一类身体能力问题上。逐际动力技术团队不仅写了这篇 BFM 综述，也在推进 BFM 全身运控基础模型。**

我会把两者写得稍微区分一下：**智元是明牌把 BFM 这条线推到产品叙事里；众擎我不会写成官方已经押注 BFM，但它的 demo 效果很像在吃“运控基座 / 行为基座”这类路线的红利。** 一个把词说出来，一个把需求拍出来。

02第一组：Forward-backward 表征，先把任务压进潜空间

这一组有 6 篇。它们没有急着堆动作数据，先问了一个更底层的问题：如果未来任务不断变化，机器人能不能先学到一个通用行为表示，再根据目标、奖励或 prompt 调出对应行为。

论文 01BFM-Zero：把人形控制做成 promptable 的身体基座

📄 **论文标题**：BFM-Zero: Promptable Behavioral Foundation Model for Humanoid Control Using Unsupervised Reinforcement Learning

📅 **年份/出处**：2025 · arXiv

🔗 **论文链接**：https://arxiv.org/abs/2511.04131

💻 **代码/项目**：https://github.com/LeCAR-Lab/BFM-Zero

![](https://mmbiz.qpic.cn/sz_mmbiz_png/icibRpSZ9SJEUUP3u5UcJA9nzJr9FKxEa7PNEsxWCgn2clRX3m5tjlVvFQkErpIcjeyu7Qib1nUVI5Bj6m0JzcYgRDYlkqpdaeRv6U12CEsuB8/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=2)

**图解：**这张图把 BFM-Zero 的未见动作跟踪、奖励优化、目标姿态到达、自然恢复和少样本适配放在一起看，最能说明它已经从单点技能走向一套可 prompt 的身体能力集合。

如果只看 demo，BFM-Zero 很容易被理解成“动作很多”。但我更在意的是另一点：目标姿态、奖励函数和动作轨迹被压进同一个 latent prompt 体系以后，技能切换开始变成一个 **搜索身体潜空间** 的问题。

这也是我为什么把它放在第一篇。它已经很接近产业里说的“运控基座”：底层不再只是一堆孤立 policy，而是一套可调用、可搜索、可组合的身体空间。

📄 **论文标题**：Zero-shot Whole-body Humanoid Control via Behavioral Foundation Models

📅 **年份/出处**：2025 · ICLR

🔗 **论文链接**：https://arxiv.org/abs/2504.11054

💻 **代码/项目**：https://github.com/facebookresearch/metamotivo

![](https://mmbiz.qpic.cn/mmbiz_png/icibRpSZ9SJEUPibfODjLzm01uES6IzIVkzW41aibAI8ovAS3t9H4Sia8riaqScnn9FGicNwFLgExEtcpwj6pv3IBB0bJicVcGEVtGnCjEVOUp2GC9w/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=3)

**图解：**这张图适合看 metamotivo 的核心位置：不同动作和目标被放进同一个行为表示里，zero-shot 控制依赖的是底层身体空间本身的可调用性。

metamotivo 和 BFM-Zero 可以放在一起读。前者更强调 zero-shot whole-body control，后者更像把 promptable control 推到人形真机语境里。

两篇合起来看，BFM 的核心价值会更清楚：任务变了以后，不一定每次都重新训练一套策略，而是尽量在已有身体表示里找到可用的方向。这个转变很重要，因为人形机器人未来不可能为每个动作、每个场景单独开炉训练。

读这篇，我会先抓一个点：**潜空间不能只大，还要细**。覆盖很多技能当然重要，但如果潜空间里的差异太粗，上层调用时只能得到一个大概方向。

FB-AW、FB-AWARE 这类设计补的是可控性。同样是“会动”，模型能不能区分更细的任务差别，能不能对局部动作变化更敏感，决定了它后面能不能被语言、规划器或者 VLA 精确调用。

Fast Imitation 的位置很清楚：当行为基座已经存在，新动作不应该再像从零学。它更像是在问，已有身体先验能不能帮模仿学习少走弯路。

这件事对机器人技能扩展很现实。以后新增一个动作，如果仍然要大量真机数据和漫长训练，那“基座”这个词就没有太多工程意义。它必须让新技能进入系统的成本降下来。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/icibRpSZ9SJEXetz2rGj4TSLOVz0eWw8US3rDiaLHUOS84sKVh1WDEtRPTQc7A8xBtVHGLMY0ZdqmnTb7NzZkz7zeiaMAD6m3qawjfVpYjzohu4/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=6)

**图解：**这张图展示同一套 FB embedding 在连续迷宫里的表示形态。左边是原始状态网格，中间和右边分别是 F embedding 与 B embedding，能更清楚地看出“统一表示”并不是抽象口号，而是在把状态拓扑压进可迁移空间。

这篇离人形机器人比较远，但它给 forward-backward 这条线打了一个底。它关心的是：能不能学到一套表示，之后面对不同 reward 时都能推导出可用策略。

放到 BFM 语境里，这句话可以翻译成：底层身体最好先学会“未来状态如何组织”，再被具体任务调用。否则所谓基座只是在多个任务上训练过，并没有真正学到可迁移结构。

Successor States 更偏数学，它不会给你一个好看的机器人视频，却能解释一件底层问题：为什么“未来状态分布”可以成为可复用控制表示。

所以我会把它放在第一组收尾。前面几篇已经开始讲 prompt、latent space 和 zero-shot control，这篇相当于把其中一部分理论土壤摊开来看。

03第二组：Goal-conditioned 学习，把动作覆盖面做大

这一组数量最多，一共 19 篇。它们共同说明一件事：人形机器人的身体基座，必须先有足够大的动作覆盖面。走、跑、转身、物体交互、遥操作、长时程任务，这些都要进入同一张身体地图。

论文 07SONIC：把 motion tracking 的规模继续做大

📄 **论文标题**：Sonic: Supersizing Motion Tracking for Natural Humanoid Whole-Body Control

📅 **年份/出处**：2025 · arXiv

🔗 **论文链接**：https://arxiv.org/abs/2511.07820

💻 **代码/项目**：https://nvlabs.github.io/SONIC/

![](https://mmbiz.qpic.cn/mmbiz_png/icibRpSZ9SJEUJ5yYica8ib3qVQRd016oUoJiawkPwfG6iaAtrV5fUAl3Zu63O8TlOjOXDl2JZk0ScKdblNrgI6jNn9fS3ISiaNJyHl64wJJzkiafbg/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=8)

**图解：**这张图展示 SONIC 在多类全身动作上的跟踪效果。它的意义很直接：运控基座要被上层调用，底层动作覆盖面必须足够宽。

到了 SONIC，问题从“表示能不能复用”转到“动作覆盖够不够大”。它的关键词是 supersizing：更多动作、更宽数据、更自然的全身控制。

这条线非常现实。上层 VLA 能调用什么，首先取决于底层身体库里到底有什么。如果低层动作覆盖很窄，上层智能再强，最后也只能在一个很窄的身体空间里打转。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/icibRpSZ9SJEXCR8PyicqgAq54wswA6khhmrBFTkI0wDxL6xvN5OJbrzzSHDuNeum1j81XvGSbSpgpaeiaXmrjduS4pF1yPygK8pM2WlGdNucv0/640?wx_fmt=png&from=appmsg&watermark=1&tp=webp&wxfrom=5&wx_lazy=1#imgIndex=9)

OpenTrack 把 motion tracking 和抗扰放在一起看，这一点很接近真实部署。机器人在视频里跟得像，只能说明第一步成立；被推、被撞、姿态偏掉以后还能接回来，才更像可用的身体能力。

我会把它看成 SONIC 后面的一个补充：前者把动作覆盖做大，这篇提醒我们，覆盖之外还要有稳定性。否则动作库再大，也很容易被现实世界的一次扰动打断。

敏捷性和稳定性本来就容易互相拉扯，这篇的价值在于直接面对异构数据下的取舍。人形机器人不可能只靠一种干净数据源长大，BFM 更是如此。

仓库还列了 10 个数据集。我不把它们算进 41 篇论文里，但这部分非常重要。BFM 要学的是身体经验，身体经验最终来自数据。数据如果只有漂亮动作，没有接触、动力学和语义，模型再大也很难真正服务机器人。

08写在最后：BFM 可能会成为人形机器人的身体 API

把这 41 篇放在一起，我的感觉很明确：BFM 还没有变成一个完全统一的产业标准，但它指向的问题已经非常清楚。

人形机器人后面一定会越来越依赖上层智能：语言模型、VLA、世界模型、任务规划器、视频生成模型都会进入系统。但这些上层模块最终都要面对同一个现实：**机器人身体不能被当成一个随便调用的黑箱。**

底层身体要能走、跑、转身、抗扰、起身、接触物体、恢复失败，还要能把这些能力封装成上层可以调用的接口。

所以我现在更愿意把 BFM 看成三件事的交汇：

-   **AMP / adversarial motion prior**
    
     给了自然身体分布的约束；
    
-   **motion tracking / mimic / teleoperation**
    
     扩大了可执行动作和交互数据；
    
-   **VLA / language / diffusion / planning**
    
     推动底层身体变成可调用接口。
    

**未来具身 AGI 不一定会保留今天这个具体的 BFM 算法形态，但一定需要 BFM 所代表的那层东西：可复用、可适配、可调用的身体基座。**

如果后面继续写，我会优先拆四条线：BFM-Zero 和 forward-backward 表征；HOVER、MaskedMimic、SONIC 代表的全身跟踪；SENTINEL、LangWBC、LeVerb 代表的语言到身体接口；以及 Humanoid-X、Motion-X++ 代表的数据路线。

这 41 篇论文搭出来的，更像是一张人形机器人运控基座的路线图。
