各模块详细步骤
Step 1
定义 Agent 职责
明确 Agent 的专业领域、触发场景、工具权限、模型选择（haiku/sonnet/opus）。
Step 2
创建 .md 文件
路径：agents/your-agent-name.md
包含 YAML frontmatter + 角色说明 + 工作流。
Step 3
注册到 AGENTS.md
在 AGENTS.md 的 Available Agents 表格中新增一行，描述触发时机。
Step 4
安装 & 测试
拷贝到 ~/.claude/agents/，用 Task tool 委托触发，验证输出格式。
agents/your-agent-name.md Markdown + YAML 
---
name: your-agent-name
description: 专业职责描述——Claude 据此决定何时调用。要具体！
tools: ["Read", "Write", "Edit", "Bash", "Grep", "Glob"]
model: sonnet         # haiku(简单) / sonnet(编码) / opus(复杂)
---

You are a [专业角色] specialist.

## Your Role

- 主要职责
- 次要职责
- 明确不做什么（边界）

## Workflow

### Step 1: Understand
分析任务，收集上下文。

### Step 2: Execute
执行核心工作，给出具体输出。

### Step 3: Verify
验证结果，确保质量 80%+ 覆盖率。

## Output Format

返回给用户/主 Agent 的格式说明。

## Examples

### Example: [场景]
Input: [用户输入]
Action: [执行动作]
Output: [返回内容]

确定规范类型
Rules 是"始终遵守"的约束。确定适用的语言/场景（common / typescript / python 等）。
Step 2

# Your Domain Coding Rules

# Rules 是 Claude 始终遵守的准则，每个会话自动加载

## 核心规则

### 规则 1：[规则名称]

**适用范围**：所有 [语言/场景] 代码

**要求**：
- 必须做 A
- 不允许做 B
- 推荐使用 C

**正例：**
\`\`\`c
// ✅ 符合规范
void safe_function(uint8_t* ptr, size_t len) {
    if (ptr == NULL || len == 0U) { return; }
    /* 安全操作 */
}
\`\`\`

**反例：**
\`\`\`c
// ❌ 违反规范：未检查空指针
void unsafe_function(uint8_t* ptr) {
    *ptr = 0;  /* 可能 NULL 解引用 */
}
\`\`\`

**原因**：[说明为何重要，引用标准编号]

### 规则 2：[规则名称]
...

## 违规处理

发现违规时：1) 停止生成 2) 指出问题 3) 给出修正方案

commands/your-command.md Markdown + YAML 
---
description: 命令简短描述——在 /help 中显示
---

# /your-command

## Purpose

本命令执行的具体操作说明。

## Usage

\`\`\`
/your-command [可选参数]
\`\`\`

## Workflow

1. 分析当前上下文（读取相关文件）
2. 调用对应 Agent：@your-agent-name 执行任务
3. 汇总结果，以 [格式] 输出给用户

## Output

用户收到的内容格式说明。

## Examples

\`\`\`
/your-command src/main.c
\`\`\`
→ 分析 main.c 并返回 [报告类型]

Step 1
确定触发事件
选择事件类型：PreToolUse（前置拦截）/ PostToolUse（后置处理）/ SessionStart / Stop。
Step 2
编写 matcher
hooks/hooks.json 中添加条目。matcher 要精确，避免过度拦截。
Step 3
编写 command
exit 1 = 阻断操作；exit 0 = 允许继续。命令输出会显示给用户/AI。
Step 4
测试拦截行为
模拟触发动作，验证 hook 正确执行。检查不应误拦截的正常操作。
hooks/hooks.json（追加条目） JSON 
{
  "hooks": {
    "PreToolUse": [
      {
        // 安全检查：阻断危险命令
        "matcher": "tool == \"Bash\" && tool_input.command matches \"rm -rf /\"",
        "hooks": [{
          "type": "command",
          "command": "echo '[Hook] BLOCKED: Dangerous command' && exit 1"
        }],
        "description": "Block dangerous rm commands"
      }
    ],
    "PostToolUse": [
      {
        // 自动格式化：编辑 .c 文件后运行 clang-format
        "matcher": "tool == \"Edit\" && tool_input.file_path matches \"\\.c$\"",
        "hooks": [{
          "type": "command",
          "command": "clang-format -i \"$file_path\""
        }],
        "description": "Auto-format C files after edit"
      }
    ],
    "SessionStart": [
      {
        // 会话启动时加载项目上下文
        "matcher": "",
        "hooks": [{
          "type": "command",
          "command": "cat PROJECT_CONTEXT.md"
        }],
        "description": "Load project context on session start"
      }
    ]
  }
}
✅ Hook 验收清单
🎯 matcher 精确（不会过度匹配）
📢 error/info 消息清晰明了
🚦 exit 1（阻断）/ exit 0（放行）用法正确
🔍 已测试正常流程不被误拦截
📝 每条 hook 有 description 字段
⚡ Hook 命令轻量快速（不阻塞工作流）

最佳实践与注意事项
⚡ 命名规范
  • 全小写 + 连字符：my-agent.md
  • 描述性命名：misra-c-reviewer 优于 reviewer
  • Skill 目录名 = frontmatter name
  • 避免与内置模块同名（会被覆盖）
🤖 Agent description 要点
  • 说明何时调用（触发条件）
  • 说明处理什么（领域范围）
  • 用 PROACTIVELY 标注主动调用
  • 长度适中（1-3 句话）
🔒 安全必须项
  • 禁止硬编码 API Key / 密码 / Token
  • Hook matcher 精确，避免过度拦截
  • Rule 覆盖输入验证和内存安全
  • 提交前用 security-reviewer Agent 检查
🔗 跨模块协作模式
  • Command → 调度 Agent → 使用 Skill
  • Hook（前置）→ 触发安全检查 Agent
  • Rule 约束 Skill 和 Agent 的行为范围
  • 在 AGENTS.md 中集中注册 orchestration 策略
快速安装命令
Terminal — 将自定义模块复制到全局目录 Bash 
# 安装单个 Agent
cp agents/your-agent.md ~/.claude/agents/

# 安装单个 Skill
cp -r skills/your-skill/ ~/.claude/skills/

# 安装整个自定义项目的所有模块
cp -r agents/   ~/.claude/agents/
cp -r skills/   ~/.claude/skills/
cp -r commands/ ~/.claude/commands/

# 安装 Rules（合并到全局规则目录）
mkdir -p ~/.claude/rules/your-domain/
cp -r rules/your-domain/ ~/.claude/rules/

# 查看已安装的 Agents
ls ~/.claude/agents/

# 在项目根目录初始化 ECC 自定义配置
cp AGENTS.md  ./AGENTS.md   # 项目级 Agent 注册
cp CLAUDE.md  ./CLAUDE.md   # 项目指令文件
