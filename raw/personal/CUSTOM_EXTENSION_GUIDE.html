② 决策：选择扩展类型
❓ 需要添加的是哪种类型的模块？
🤖 Agent（智能体）
需要一个具备特定领域
专业知识的对话专家

需要封装一段专业知识
或代码生成模板
📏 Rule（规则）
需要强制约束代码生成
符合特定编码/安全标准

需要一个可直接调用的
预定义 /斜线命令

📄 Rule 文档模板
# rules/coding-standards/my-company-coding.md # 公司内部编码规范 v1.0 ## 适用范围 - 所有 ASIL-B 及以上等级的 C/C++ 代码 - 适用标准: MISRA C:2012 + 公司扩展规则 --- ## 强制规则（违反即阻断提交） ### MY-C-001: 函数长度限制 ❌ 禁止: 单函数超过 60 行代码 ✅ 要求: 超过时必须拆分为子函数 原因: 可读性与可测试性 ### MY-C-002: 命名规范 ✅ 全局变量: g_<模块名>_<变量名> ✅ 静态变量: s_<变量名> ✅ 宏定义: MY_MACRO_NAME (全大写) ✅ 函数名: ModuleName_FunctionName ### MY-C-003: ASIL 注释 ✅ 所有 ASIL-B+ 函数顶部必须注释: /* @ASIL{B} */ /* @req [需求编号] */ /* @wcet [最坏执行时间] */ --- ## 建议规则（警告但不阻断） ### MY-C-010: 注释语言 推荐使用英文注释（方便国际协作） --- ## 偏差处理 若必须偏离以上规则，需： 1. 添加 DEVIATION 注释块 2. 说明偏离原因 3. 获得安全团队审批 /* DEVIATION: MY-C-001 Reason: [原因] Approval: Safety Lead, [日期] */

📄 Command 文档模板
# /automotive-my-domain-analyze # 在 commands/my-domain/my-analyze.md 中创建 ## 功能描述 对 [特定目标] 执行 [专业分析类型]， 输出符合 [相关标准] 的分析报告。 ## 参数说明 | 参数 | 类型 | 默认值 | 说明 | |------|------|--------|------| | `--target` | 文件路径 | 当前文件 | 分析目标 | | `--level` | basic/full | full | 分析深度 | | `--standard` | 字符串 | ISO26262 | 参考标准 | | `--output` | 文件路径 | stdout | 输出位置 | ## 使用示例 ### 示例1: 基本分析 ``` /automotive-my-domain-analyze --target src/my_ecu.c ``` ### 示例2: 完整报告 ``` /automotive-my-domain-analyze \ --target src/ \ --level full \ --standard ISO26262 \ --output reports/my-analysis.md ``` ## Agent 执行流程 激活后，按以下步骤执行： 1. 读取并解析目标文件 2. 激活相关 Skills (automotive-my-skill) 3. 应用规则约束 (rules/my-rules) 4. 执行专业分析算法 5. 生成结构化报告 6. 验证输出符合标准要求 ## 输出格式 ``` MY-DOMAIN 分析报告 ================== 文件: [目标文件] 标准: [参考标准] [分析结果内容] ✅ 通过: [通过项] ⚠ 警告: [警告项] ❌ 错误: [错误项] ```

④ 安装部署到 Claude Code
⬇️
方式1: 完整安装（含自定义）
./install.sh
自动扫描所有 agents/ skills/ commands/ rules/ 目录并安装到 ~/.claude/
📦
方式2: 指定目录安装
# 安装指定 agent 目录 ./install.sh \ --include-custom agents/my-domain/ # 安装指定 skill ./install.sh \ --include-custom skills/automotive-my-skill/ # 安装到指定项目 ./install.sh \ --project /path/to/my/project
👁️
方式3: 预览模式（推荐先运行）
# 预览将要安装的内容（不实际安装） ./install.sh --dry-run # 检查安装状态 ./install.sh --status # 如需回滚，卸载自定义内容 ./install.sh --uninstall \ --custom-only
📂
安装目标路径
~/.claude/ ← 安装根目录 ├── agents/ │ └── automotive-my-domain/ ├── commands/ │ └── automotive-my-domain/ ├── skills/ │ └── automotive-my-skill/ └── rules/ └── my-coding-rules/
