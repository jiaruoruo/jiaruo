# GB/T 34590-3（征求意见稿）— 第3部分：概念阶段

## Summary

GB/T 34590 第 3 部分（征求意见稿）是 ISO 26262-3 的中国国家标准对应版本，规定概念阶段的活动：相关项定义（item definition）、危害分析与风险评估（HARA）、安全目标（safety goal）及其 ASIL 定级。内容与 ISO 26262-3 对应，当前为**征求意见稿**。

## Key Points

- **相关项定义**：描述功能、接口、环境、法规与运行场景，作为 HARA 输入。
- **HARA**：按严重度（S）、暴露概率（E）、可控性（C）评定 ASIL，导出安全目标。
- **安全目标**：顶层安全需求，含 ASIL 等级与安全状态。
- **外部措施**：在 HARA 中作为可控性/暴露边界，不属 ISO 26262 内部安全机制。
- **状态提示**：征求意见稿，与正式版可能存在差异。
