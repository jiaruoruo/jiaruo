# 灵境智源 N210/N1000 方案用于矿区无人矿卡

## Key Points

- **[[mscape-tech]]** N210 + N1000 为矿卡定制域控级自动驾驶大脑及小脑
- 融合激光雷达、毫米波雷达与视觉传感器，多模态数据融合 + VLM 环境语义理解
- 具备翻浆路面自主行驶、动态避障、挡墙自适应停靠等能力
- 部署轮臂式具身套件与 5G 模组，构建车-路-云一体化系统
- 支持有人/无人车辆混编混行，可自主完成采矿、搬运、调度

## Context

[[mscape-tech]] 面向恶劣矿区环境的无人矿卡自动驾驶方案，解决人工驾驶安全隐患与高成本问题。
