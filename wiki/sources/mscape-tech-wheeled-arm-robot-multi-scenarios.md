# 灵境智源 轮式机械臂机器人多场景应用方案

**来源**：[[mscape-tech]] · www.mscapetech.com/index/yingyong/detail/id/10004

## 主要内容

本页介绍灵境智源 N 系列/T 系列在轮式机械臂场景的四类落地方案，核心算力平台为 [[robot-brain-compute-platform]]。

### 工业制造场景（N1000）

- 平台：N1000（2070 TFLOPS）
- 尺寸：118×126 mm 高度集成
- 接口：18 路多协议连接器
- 感知：14 路摄像头 + 4 路 EtherCAT + 4 路 CAN FD

### 物流分拣场景（N201）

- 平台：N201 + Xenomai 实时内核
- 中断响应：亚微秒级
- 通信：Wi-Fi 7 抗干扰
- 特点：高实时性调度

### 商业清洁场景（N210 + T40 异构）

- 平台：N210 + T40 异构融合
- SLAM 精度：±2 cm
- 运动控制频率：2000 Hz
- 接触力感知：0.5 N

### 数据采集场景（T-S100 + N200 + T40）

- 平台：T-S100 硅皮质 + N200 大脑 + T40
- 相机：8 路 GMSL 摄像头
- 接口：6 路 USB 3.0 + LiDAR + IMU
- 特点：硬件级多传感器时间同步
