# 灵境智源 T41 方案用于四足机器狗

## Key Points

- **[[mscape-tech]]** T41 系列集成小脑与大脑算力于极小尺寸
- 8 核 CPU，2 路商用 EtherCAT，Xenomai 实时系统，12 路 CAN FD，4 路高速 485
- SBUS 遥控通道，Wi-Fi 7 高带宽无线
- 可选配高达 170 TOPS 大脑算力，支持语音交互、SLAM 导航、YOLO/ResNet
- 痛点：RK3588 在 IO 种类/数量/性能上不满足四足机器人高阶需求

## Context

[[mscape-tech]] T41 为四足机器狗提供轻量化、高集成的专用方案，将背包大脑功能内化。
