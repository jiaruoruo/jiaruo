# SGS AFSP Day 2 — TSC Exercise Page 1: Introduction & System Draft

## Summary

本页为 SGS AFSP Day 2 **Technical Safety Concept（TSC）** 练习 5 页材料中的第 1 页。说明 TSC 是从 FSC 的初步安全架构出发，以技术视角逐步展开的系统草案（system draft）。页面给出 E/E 系统草案框图：Pedal Sensor → Motor-ECU → Power Unit with Motor Monitoring → E-Motor；同时标注 CAN-Bus（ABS 速度信号）、硬线反馈、硬线 Torque off、400V Battery、Display 等接口。

## Key Points

- **TSC 定位**：ISO 26262 产品开发阶段（Part 4）的系统级技术安全概念，连接 FSC 与具体硬件/软件实现。
- **System Draft**：将 FSC 的功能元素替换为技术组件（传感器、控制单元等），并考虑车辆架构约束。
- **框图元素**：Pedal Sensor、Motor-ECU、Power Unit with Motor Monitoring、E-Motor、400V Battery、CAN-Bus（ABS speed signal）、Display（other item, QM）。
- **考试关联**：TSC 与 FSC 的区别是 AFSP 高频考点；TSC 关注技术实现，FSC 关注功能行为。
