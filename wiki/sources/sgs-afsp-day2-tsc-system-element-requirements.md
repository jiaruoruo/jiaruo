# SGS AFSP Day 2 — TSC Exercise Page 4: System Element Safety Requirements

## Summary

本页为 SGS AFSP Day 2 TSC 练习 5 页材料中的第 4 页，聚焦系统元素 **"Power Unit and Motor Monitoring"**。将系统级 SYSR 进一步细化为元素级安全要求 SYSELR1–SYSELR7，分别覆盖故障检测与控制、HW 架构指标、PMHF 预算。

## Key Points

- **元素级要求编号**：SYSELR1–SYSELR4（检测与控制），SYSELR5–SYSELR6（HW 架构指标），SYSELR7（PMHF）。
- **已填示例**：
  - SYSELR1：使用分流电阻持续测量电机工作电流（ASIL B）
  - SYSELR2：以标准化信号（0.1–10V）持续向 ECU 发送电流值（ASIL B）
- **考试关联**：ISO 26262 要求从系统级到元素级逐层细化安全要求；ASIL 可继承或分解。
- **注意**：页面为部分填写的练习模板。
