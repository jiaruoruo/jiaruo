# 灵境智源 N1000 具身大脑用于轮臂式机器人

## Key Points

- **[[mscape-tech]]** N1000 具身大脑：2070 TFLOPS 算力，支持轮臂式机器人端到端闭环决策
- 尺寸 118×126mm，可置入机器人胸腔，避免线缆疲劳损耗问题
- 航空级散热，GPU 结温低于行业均值 20°C
- 自定义车规连接器（100mm 长度内集成 18 路接口）：14 路相机 + 4 路 EtherCAT + 4 路 CAN FD
- 感知、决策、控制一体化融合；支持 VLA 大模型

## Context

[[mscape-tech]] 针对轮臂式机器人（工业制造/物流分拣/商业清洁/数据采集）的具身大脑方案。
