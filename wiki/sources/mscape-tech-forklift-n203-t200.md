# 灵境智源 N203/T200 方案用于无人叉车

## Key Points

- **[[mscape-tech]]** N203/T200 计算平台为核心，接入 8 路传感器（3D 激光雷达 + 高清摄像头）
- 集成环境建模与实时感知算法，快速识别非标货架与货物，增强泛化能力
- 智能路径规划与动态避障，深度学习算法精准识别不规则货物
- 配备科大讯飞智能交互系统，支持语音/指令简单操作

## Context

[[mscape-tech]] 将具身智能技术应用于无人叉车，解决非标场景适应性差、路径规划僵化等痛点。
