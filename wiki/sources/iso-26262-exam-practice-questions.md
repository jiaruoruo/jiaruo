# ISO 26262 功能安全证书考试—模拟题库

## Summary

ISO 26262 功能安全证书考试模拟题库（2026-07-08，8/3考试），含选择/场景/流程/论述/计算五类共17题，覆盖故障链、ASIL、HARA、安全机制、PMHF计算及与域控制器项目的关联。

## Key Points

- 选择题辨析：故障链方向、2018版新增Part11(半导体)/Part12(摩托)、功能安全=消除不合理风险、HARA三维度、ASIL分解、随机硬件三指标(SPF/LatF/PMHF非FIT)
- 场景题：ESP失效高速撞墙→S3+E2+E4/5→ASIL D；ASIL D分解为B+B需论证独立性/诊断覆盖率/PMHF/接口安全/共因
- 流程题：HARA→安全目标→功能安全概念→系统/硬件/软件需求→追溯管理；各Part主要输出
- 论述题：安全机制四类型(冗余/监控/诊断/降级)以ACU为例；追溯性管理必要性(Part8)
- 计算题：PMHF=单点贡献+潜伏贡献，重点理解概念非手算
- 域控制器关联：跨域通信安全/安全目标协调/共享资源隔离/共因故障/端到端追溯；主被动安全融合的功能安全保障
