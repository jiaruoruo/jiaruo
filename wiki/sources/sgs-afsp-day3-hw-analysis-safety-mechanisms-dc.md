# SGS AFSP Day 3 — HW Analysis Exercise Page 5: Safety Mechanisms & Diagnostic Coverage

## Summary

本页为 SGS AFSP Day 3 HW Analysis 练习 8 页材料中的第 5 页，给出 **Safety Mechanisms（SM）及其 Diagnostic Coverage（DC）** 表。示例安全机制 SM1 为 "Monitoring of motor current"，参考 ISO 26262-5 Table 3（电气元件在线监测），要求填写其可达成的 DC 等级。

## Key Points

- **安全机制 SM1**：在线监测电机电流。
- **参考标准**：ISO 26262-5 Table 3，Online Monitoring of electrical elements。
- **诊断覆盖率（DC）**：需根据故障模式覆盖比例填写（如 Low/Medium/High，对应 60%/70%/80% 或 90%/99% 等区间，依 ISO 26262-5 定义）。
- **考试关联**：DC 是计算 SPFM（Single-Point Fault Metric）和 Latent-Fault Metric 的关键参数；不同安全机制对应不同 DC 等级，AFSP 考试常考典型安全机制及其 DC 分类。
- **注意**：本页为空白练习表，用于学员判断并填写 DC。
