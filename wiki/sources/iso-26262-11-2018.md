# ISO 26262-11:2018 — Part 11: Guidelines on application of semiconductor components (informative)

## Summary

ISO 26262 第 11 部分为信息性指南，专门指导半导体元器件如何按 ISO 26262 进行安全分析与应用。涵盖半导体组件的划分、故障模型与失效模式、基础失效率（base failure rate）估计方法、半导体相关失效分析（DFA）以及 IP（知识产权）模块的安全要求与集成。是 SGS AFSP 培训 Day 3 中 SN 29500 元器件失效率查表与硬件度量的上游理论依据。

## Key Points

- **半导体组件划分**：将 IC 划分为可独立分析的部件（part），区分供应商与集成方责任。
- **故障模型与失效模式**：永久/瞬态故障，基础失效率在各失效模式间的分配。
- **基础失效率估计**：SN 29500、IEC 62380、FIDES 等数据来源与计算方法（永久/瞬态）。
- **半导体 DFA（Dependent Failure Analysis）**：闩锁、串扰、共因等半导体特有相关失效。
- **IP 安全**：黑盒/白盒 IP 的类别、安全要求、生命周期与集成（含第三方 IP）。
- **与 Part 5 衔接**：本部分的失效率与 DFA 直接支撑 Part 5 的 PMHF/SPFM/LFM 计算。
