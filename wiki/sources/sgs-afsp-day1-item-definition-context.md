# SGS AFSP Day 1 — Training Example: Item Definition Context

## Summary

本页为 SGS TÜV Saar ISO 26262 AFSP（汽车功能安全专业人员）Day 1 培训示例的第 2 页，围绕某电子动力/转矩相关 item 的 **Item Definition** 展开，列出环境条件、适用法规标准以及外部风险降低措施。内容为英文表格与条目，典型于 ISO 26262-3:2018 概念阶段对 item 运行环境、外部安全措施及法规边界的描述。

## Key Points

- **环境条件**：Item 用于公共道路交通，需在环境规范中进一步细化。
- **法规与标准**：
  - ECE-R100（欧洲）
  - 其他国家/地区适用法规
  - ISO 26262
- **外部风险降低措施（External Measures）**：
  - 驾驶员需持驾照
  - 主动与被动安全功能（安全气囊、安全带等）
  - 独立的机械驻车装置，防止停车时非预期移动
- **考试关联**：Item Definition 是 HARA 的前置输入；外部措施不属于 ISO 26262 内部安全机制，但影响 ASIL 定级时的可控性/暴露度评估。
