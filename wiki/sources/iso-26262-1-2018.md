# ISO 26262-1:2018 — Part 1: Vocabulary（术语）

## Summary

ISO 26262 第 1 部分为整套标准的术语与缩略语基础，定义了功能安全活动中使用的全部关键概念，包括 item、element、component、hardware part、software unit、fault/error/failure、hazard、harm、safety goal、functional safety、ASIL、FTTI、safe state 等，并给出 ASIL、FTTI、E/E、QM、HARA、FSC、TSC、SNR、SSR、HSR、SWC 等缩略语。理解本部分是正确解读其余 11 个部分的前提。

## Key Points

- **核心定义**：item（实现某项或多项功能的功能装置或系统组合）、element、component、hardware part、software unit。
- **故障链**：fault（物理原因）→ error（内部状态偏离）→ failure（功能偏离），是硬件可靠性与诊断覆盖率分析的基石。
- **安全相关概念**：hazard（潜在危害源）、harm（人身伤害/健康损害）、hazardous event、safety goal、functional safety、ASIL、FTTI、safe state、emergency operation tolerant time interval。
- **缩略语表**：集中列出贯穿全套标准的缩写，便于跨部分查阅。
- **位置**：本部分不含要求条款，仅为规范性引用与定义，是后续各部分的索引基础。
