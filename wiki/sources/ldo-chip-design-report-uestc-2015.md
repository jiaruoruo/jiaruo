# LDO芯片设计报告及电路分析（UESTC，2015）

## Summary

电子科技大学VLSI设计中心2015年LDO（低压差线性稳压器）芯片设计报告（60页）。涉及LDO工作原理、电路结构分析、仿真结果及版图设计。⚠ 此来源发表于2年以上前，部分内容可能已过时。

## Key Points

- LDO工作原理：Pass元件、误差放大器、反馈网络
- 关键参数：压差（Dropout）、PSRR、负载调整率
- Cadence Spectre仿真验证
- 版图设计规则与注意事项
