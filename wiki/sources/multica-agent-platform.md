# GitHub 热点 | Multica: Agent即队友

## Summary

GitHub Trending 项目 Multica 介绍：一个开源托管式 Agent 平台（Go，31K+ Stars），核心使命是把编码 Agent 变成团队真正的「队友」。用户可像给人类同事分配 issue 一样把任务分配给有独立身份的 Agent，Agent 自主认领、分析代码库、写代码、跑测试、提 PR，遇阻时主动在看板留言。

## Key Points

- 范式跃迁：Agent 从「使用工具」到「管理团队」——拥有独立身份、可看板拖拽分配的一等公民成员
- 命名致敬 Multics 分时系统：Multiplexed Information and Computing Agent，用多路复用在人与 Agent 间共享系统资源
- Squads 编队：给 Agent 团队建立组织架构；可复用技能形成「能力复利」飞轮（见 [[agent-harness]]）
- 自主执行与统一运行时：「分配完就不用管」
- MIT 开源，单日新增 534 Stars，反映社区对「Agent 融入团队工作流」的强烈认可
