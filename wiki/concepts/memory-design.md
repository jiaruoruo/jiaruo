# 存储器设计（Memory Design）

## Definition

存储器设计（Memory Design）针对 SRAM、DRAM、Flash 等存储器件的电路结构与阵列设计，强调存储密度、访问速度、功耗与可靠性的权衡。是芯片设计（见 [[chip-design]]）的重要分支，存储单元的版图密度直接决定芯片成本。

## Key Points

- 主要类型：SRAM、DRAM、Flash
- 核心权衡：存储密度、访问速度、功耗、可靠性
- 存储单元版图密度决定芯片成本
- 属于芯片设计（见 [[chip-design]]）的专门分支
