# ARM 体系结构（ARM Architecture）

## Definition

ARM 体系结构（ARM Architecture）是由 Arm 公司定义的精简指令集（RISC）处理器架构，以低功耗、高能效著称，通过 IP 授权模式被广泛用于嵌入式系统（见 [[embedded-system]]）与移动 SoC（见 [[mobile-soc]]）。涵盖指令集、寻址方式、异常处理、存储系统等核心规范。

## Key Points

- RISC 精简指令集，强调低功耗与高能效
- IP 授权商业模式，被高通/联发科/苹果等广泛采用
- 核心要素：指令集、寻址方式、异常处理、存储系统
- 是嵌入式系统（见 [[embedded-system]]）与移动 SoC 的主流处理器架构
