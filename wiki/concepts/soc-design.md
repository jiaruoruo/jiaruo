# SoC 设计（SoC Design）

## Definition

SoC 设计（System-on-Chip Design，片上系统设计）是将处理器、存储、外设、接口等完整系统功能集成到单颗芯片上的设计方法，强调 IP 复用与系统级集成。设计后期常用 ECO（工程变更令）进行局部修改以快速响应需求变化。

## Key Points

- 将完整系统功能集成到单颗芯片
- 强调 IP 复用与系统级集成验证
- 后期变更依赖 ECO（工程变更令）局部修改
- 是移动 SoC（见 [[mobile-soc]]）等产品的设计基础
