# 移动 SoC（Mobile SoC）

## Definition

移动 SoC（Mobile System-on-Chip）是面向智能手机、平板等移动设备的片上系统芯片，在单颗芯片上集成 CPU、GPU、基带（Modem）、ISP、NPU 等模块。代表厂商包括高通（见 [[qualcomm]]）、联发科（见 [[mediatek]]），强调能效比与集成度。

## Key Points

- 集成模块：CPU + GPU + 基带 + ISP + NPU 等
- 核心指标：能效比、制程工艺、AI 算力
- 主要厂商：高通（见 [[qualcomm]]）、联发科（见 [[mediatek]]）、苹果、三星
- 基于 ARM 架构（见 [[arm-architecture]]）授权设计
