# GB/T 34590（道路车辆 功能安全，中国国家标准）

## Definition

GB/T 34590《道路车辆 功能安全》是 ISO 26262 的中国国家标准等同/修改采用版本，同样分为 12 个部分，覆盖功能安全的术语、管理、概念阶段、系统/硬件/软件产品开发、生产运行、支持过程、ASIL 导向分析，以及指南、半导体应用指南与摩托车适用性。知识库现有文件为 **征求意见稿（draft for comments）**，尚未发布为正式版本。

## Key Points

- **法律地位**：与 ISO 26262 内容对应，是中国道路车辆功能安全合规的主要依据；正式发布后将成为强约束。
- **当前状态**：本批次为「征求意见稿」，不等同于正式标准，引用时需注意版本时效。
- **结构对应**：Part 1–12 与 ISO 26262 Part 1–12 一一对应（术语 / 管理 / 概念 / 系统 / 硬件 / 软件 / 生产运行 / 支持过程 / ASIL 分析 / 指南 / 半导体指南 / 摩托车）。
- **与 ISO 26262 的关系**：技术内容同源，差异主要体现在术语本地化与少量国情适配（见 [[iso-26262]]）。
