# 博通（Broadcom）

## Description

博通（Broadcom）是美国半导体与基础设施软件公司，在有线/无线通信、射频芯片（见 [[rf-chip-design]]）、网络交换芯片等领域技术领先。

## Key Contributions

- 射频与无线连接芯片的主要供应商
- 数据中心网络交换芯片领导者
