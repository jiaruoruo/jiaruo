# 联发科（MediaTek）

## Description

联发科（MediaTek，MTK）是中国台湾无晶圆半导体公司，以天玑（Dimensity）等移动 SoC（见 [[mobile-soc]]）和多媒体芯片著称，是全球出货量领先的手机芯片供应商之一。

## Key Contributions

- 天玑/Helio 系列移动 SoC 供应商
- 以高性价比芯片占据中端手机市场
