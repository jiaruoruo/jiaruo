# Claude Opus 4

## Definition

Claude Opus 4 是 Anthropic 于 2025 年发布的旗舰大模型，属 Opus 系列最高智能档位。在 Agent 工程语境中常被用作感知层（意图识别/结构化提取）与规划层（LLM 生成计划）的核心模型。

## Key Points

- **定位**：Anthropic 旗舰大模型，高智能档位
- **Agent 路线图关联**：Knock「Agent 6 层架构」将其列为 2026 年感知层推荐模型（与 GPT-5.5 并列）
- **生态关联**：Anthropic 同时主导 [[model-context-protocol|MCP]] 标准，Claude 原生支持 MCP
