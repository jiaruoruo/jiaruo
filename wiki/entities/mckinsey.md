# 麦肯锡咨询（McKinsey & Company）

## Description

全球顶级战略管理咨询公司，工业实践部门（Industrials Practice）聚焦先进制造、汽车、机器人等领域的深度战略研究，定期发布具有行业影响力的白皮书与市场预测报告。在人形机器人领域，其研究涵盖供应链成熟度、BOM 成本拆解和规模化路径分析。

## Key Contributions

- **人形机器人供应链分析（2026）**：系统拆解 BOM 五大硬件领域成本占比，提出"价值集中点与供应商准备度错配"框架，绘制三级供应瓶颈风险图
- **供应链分化预判**：中国凭借制造生态深度优先实现硬件规模化；美欧通过前沿 AI 与认证能力差异化
- **成本定量测算**：不用中国供应商制造 Optimus Gen 2，BOM 从 ~$46,000 飙升至 ~$131,000（约 3 倍）
