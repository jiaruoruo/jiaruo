# LangGraph

## Definition

LangGraph 是 LangChain 生态推出的 Agent 工作流编排框架，以图（节点+边）方式可视化编排多步任务，是 2026 年 Agent 规划层的主流技术栈之一（与 CrewAI 并列）。支持循环、条件分支、持久化状态等人形 Agent 所需的控制流特性。

## Key Points

- **定位**：Agent 规划/编排框架，将多步任务建模为有向图
- **核心能力**：循环（loop）、条件边（conditional edge）、状态持久化（checkpoint）、Human-in-the-Loop 中断恢复
- **路线图关联**：在 Knock「Agent 6 层架构」中被列为规划层推荐工具（GPT-5.5/Claude Opus 4 + LangGraph/CrewAI）
